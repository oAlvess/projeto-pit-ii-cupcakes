# Projeto Integrador Transdisciplinar II — Engenharia de Software

Projeto acadêmico desenvolvido para o curso de Engenharia de Software, com foco em um sistema de catálogo e vendas de cupcakes.

## Organização do repositório

O projeto está dividido em duas versões:

- **01_cupcakes_versao_inicial:** versão inicial do sistema, utilizada como base para o desenvolvimento.
- **02_cupcakes_versao_melhorada:** versão evoluída, com funcionalidades adicionais e melhorias na experiência de utilização.

## Tecnologias utilizadas

- Python
- Flask
- SQLite
- HTML e CSS
- JavaScript
- Jinja2
- Pytest

## Objetivo

Demonstrar a evolução do sistema, a implementação de melhorias, a organização do código e a aplicação de testes.

## Execução

Cada pasta possui seu próprio README.md com instruções específicas para instalação, execução e testes.

## Projeto acadêmico

Projeto desenvolvido como parte das atividades do Projeto Integrador Transdisciplinar em Engenharia de Software II.
