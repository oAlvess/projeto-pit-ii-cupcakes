# Cupcakes — versão inicial (PIT II)

Projeto-base recebido, preservado para demonstrar a primeira versão.

## Tecnologias
- Python e Flask
- SQLite
- HTML, CSS e Jinja2
- Pytest

## Executar
1. Abra o terminal nesta pasta.
2. Crie e ative um ambiente virtual (opcional, recomendado).
3. Instale as dependências: `pip install -r requirements.txt`.
4. Inicie: `python app.py`.
5. Acesse `http://127.0.0.1:5000`.

## Testes
Execute `pytest -q`.

Esta versão mantém as funcionalidades que estavam no ZIP original: listagem do cardápio, filtro por categoria e indicação de produto esgotado.
